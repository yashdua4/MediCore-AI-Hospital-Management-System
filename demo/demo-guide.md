# MediCore AI Demo Presentation Guide

This guide details the pre-presentation checklist, user credentials, presentation flow, and step-by-step scripts for presenting the **MediCore AI Hospital Management System**.

---

## 1. Pre-Presentation Checklist

- [ ] **Database State**: Execute `npm run db:seed-demo` in the backend directory to reset the environment to a clean database state.
- [ ] **Services Check**: Ensure the backend is running on port `5000` and the frontend is running on port `5173` (dev) or `3000` (Docker).
- [ ] **Health Checks**: Verify `curl http://localhost:5000/ready` returns `READY` and database is connected.
- [ ] **Access Credentials**: Open 3 separate browser windows (or 2 browsers + 1 incognito tab) to demonstrate simultaneous multi-user interactions.

## 3. Demo Walkthrough Script

### Scene A: Patient Registration & Appointment Scheduling (Receptionist)
1. Log in as `receptionist@medicore.com` on Browser Window 1.
2. Navigate to **Appointments**. Notice the calendar overview.
3. Click "Book Appointment".
4. Select Patient: `John Doe` (Profile `patient@medicore.com`).
5. Choose Doctor Elizabeth Blackwell (General Medicine).
6. Pick tomorrow's date at `10:00 AM` and hit **Confirm booking**.
7. The appointment card appears in the list under the status **Requested**.

---

### Scene B: OPD Check-in & Nurse Vitals Logging (Receptionist / Nurse)
1. On Browser Window 1 (Receptionist), select the newly booked appointment.
2. Click the status action **Confirm Appointment**. The status updates to `CONFIRMED`.
3. When the patient arrives, click **Patient Check-in**. The status transitions to `CHECKED_IN`.
4. This instantly adds the patient to Doctor Blackwell's waiting list queue.

---

### Scene C: Doctor Consultation & EMR Recording (Doctor)
1. Log in as `doctor@medicore.com` on Browser Window 2.
2. Navigate to **Dashboard** -> Today's Patients. John Doe is now visible as `CHECKED_IN`.
3. Click **Start Consult**. The appointment status shifts to `IN_CONSULTATION`.
4. Open the EMR editor panel:
   - Input Symptoms: `Shortness of breath, mild chest tightness`.
   - Add ICD-10 Diagnosis: `J45.909` - `Asthma, unspecified`.
   - Log Vitals: BP `120/80`, Heart Rate `78`, Temperature `37.2`°C.
   - Prescribe: `Albuterol Inhaler` (90 mcg, 2 puffs every 4 hours as needed, 30 days).
5. Click **Save EMR File**. This initiates version 1 of the patient's HIPAA medical record.
6. Click **Order Lab Test**: Select `Complete Blood Count (CBC)` from the dropdown catalog, and select **High Priority**. Click Submit.

---

### Scene D: Blood Sample Processing & Result Logs (Lab Tech)
1. Log in as `labtech@medicore.com` on Browser Window 3.
2. Go to **Lab Worklist**. The new high-priority CBC order for John Doe is visible.
3. Click **Assign to Self** -> **Collect Sample** (Blood, stored in ED-FRIDGE-1).
4. Update status to **Processing**.
5. Once analytics are done, click **Log Values**:
   - Parameter: `Hemoglobin`.
   - Value: `11.5` g/dL. (This triggers a `LOW` warning flag since the reference range is 13.5 - 17.5).
6. Click **Submit Results**.
7. Logged results are verified by clicking **Verify & Approve**. The lab order changes to `COMPLETED`.

---

### Scene E: Billing Ledger Settlement (Billing Exec / Patient)
1. Log in as `billing@medicore.com` on Browser Window 1 (or log in as the patient portal user).
2. Go to **Invoices**. Click **Create Draft Invoice**:
   - Link Patient: John Doe.
   - Add item: `Consultation Fee` ($500.00).
   - Add item: `CBC Lab Assay` ($500.00).
   - Apply discount: $100.00.
3. Click **Finalize Invoice**. The ledger computes a subtotal of $1000.00, $180.00 tax (18%), and a total of $1080.00 outstanding.
4. Log in as `patient@medicore.com` in a private tab.
5. Go to **Billing & Insurance**. The $1080.00 outstanding bill is visible.
6. Click **Settle Bill** -> Select UPI/Card payment -> Click Pay.
7. The payment is processed and the invoice status immediately updates to **Paid**.
